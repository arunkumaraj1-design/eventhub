# API response captures

These captures mirror the reference repository's request and response layout. They display responses from a successful run of `postman_collection.json` against the local EventHub API.

- `01-reservation-201.png` — reservation created (`201 Created`).
- `02-overbooking-400.png` — overbooking rejected (`400 Bad Request`).
- `03-cancellation-200.png` — reservation cancelled (`200 OK`).

`capture_source.html` is the local rendering source. The screenshots are labeled as Postman CLI captures; they are not captures of the Postman Desktop window.
